## 第一步：下载安装 Codex

## 提前安装原版官方 Codex 桌面客户端，不用登录。

## 注意：不要从微软商店下载 Codex，商店版更新慢，可能不兼容最新的 Codex++ 功能。

## 第二步：下载安装 Codex++

1. 整个过程 5 分钟就能搞定，直接去 GitHub 下载Codex++

如果你不知道GitHub的Codex++ 下载链接，请联系博主发给你哦

## 2. 安装完成后，你会得到两个图标

安装完桌面会出现两个快捷方式，别搞混了：

- 🚀 **Codex++** ：启动器，必须用它来启动 Codex，不然增强功能不生效

- ⚙️ **Codex++ 管理工具** ：配置中心，用来加 API、切换供应商、看使用记录

## 第三步：准备你的多个 API 密钥

我们要准备 API，一个用来处理复杂任务，一个用来处理日常轻量任务，搭配着用最省钱。

## 👉 第一个：高级的 API（第三方购买即可）

如果你已经有第三方渠道买的 API Key，直接用就行。如果你不知道第三方渠道，请联系博主可以给你推荐我正在使用的。

- 配置的时候，只要拿到你的 API Key 和对应的 Base URL（如果是第三方中转的话）

- 这个用来处理复杂的架构设计、多模态任务，虽然贵一点，但效果最好

## 👉 第二个：DeepSeek API（便宜到离谱的国产神器）

日常写代码、改 bug、查文档这些简单任务，用 DeepSeek 就够了，价格只有 国外 的 1/10 都不到！

### 怎么买 DeepSeek API？超简单，国内就能搞定：

- 打开 DeepSeek 开放平台：https://platform.deepseek.com

- 用国内手机号注册登录，不用海外信息，10 秒搞定

- 点击左侧「充值」，支持支付宝 / 微信，最低充 10 块钱，够你用大半个月

- 然后进入「API Keys」，点击「创建 API Key」，复制生成的 Key（注意只显示一次，一定要存好！）

## 第四步：配置API的供应商，实现自由切换

现在打开「Codex++ 管理工具」，我们来把多个 API 都加上，这样想用哪个就切哪个。

填完保存，两个供应商就都配置好了！

## 第五步：启动使用，灵活搭配干活

配置完之后，
一定要用桌面的
**Codex++**
图标来启动 Codex
，别用原来的快捷方式！不然代理和增强功能都不生效。

启动之后，你会发现 Codex 的界面和原来一模一样，但是顶部多了一个 Codex++ 的状态灯，点进去就能随时切换供应商！

## 怎么搭配API最划算？

我自己的用法是这样的，给大家参考：

- **新项目初始化、架构设计、需要识图的任务** ：切到 供应商，用 GPT-4o 来做，虽然贵点，但这些复杂任务它处理得最好

- **日常写代码、改 bug、重构、查文档、写注释** ：切到 DeepSeek 供应商，用 V4-Flash，速度快，而且便宜到几乎不要钱，写一天代码可能才花几毛钱
